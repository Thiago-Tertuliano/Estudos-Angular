# Aula prática — Módulo 01

## Como usar

1. Abra [`exercicios/GUIA-PASSO-A-PASSO.md`](../exercicios/GUIA-PASSO-A-PASSO.md)
2. Para cada arquivo, **copie** de `scaffold/` para seu `angular-lab`
3. Complete apenas as linhas marcadas com `// TODO:`
4. Se travar, compare com `gabarito/` (não copie — redigite)

## Copiar scaffold → angular-lab

| De (este repo) | Para (seu projeto) |
|----------------|-------------------|
| `scaffold/counter.component.ts` | `aula-pratica/angular-lab/src/app/features/playground/ui/counter.component.ts` |
| `scaffold/product-card.component.ts` | `.../ui/product-card.component.ts` |
| `scaffold/product-list.component.ts` | `.../ui/product-list.component.ts` |
| `scaffold/playground.page.ts` | `.../pages/playground.page.ts` |

## Ordem recomendada

1. counter → 2. product-card → 3. product-list → 4. playground.page → 5. app.routes.ts
